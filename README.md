# Stream Bot

Мод для Geometry Dash 2.2 (2.2081, Geode 5.11.2+). Простой бот: читает `.gdr2` макрос и кликает по нему. Умеет начинать не с нуля, а **с того места, где ты стоишь** — то есть работает со start pos (90%, 52%) и в практике.

## Как это работает

Макрос хранит только время кликов, без координат. Поэтому мод строит **карту «время → X игрока»**:

- пока ты играешь уровень, мод каждый кадр запоминает, на какой X был на каком времени макроса;
- когда начинается попытка (start pos, чекпоинт, обычный старт), мод смотрит твой X и по карте находит соответствующее время макроса — это и есть оффсет;
- дальше клики воспроизводятся с этим оффсетом.

Карта сохраняется в папку мода (`geode/config/gleb.streambot/maps/<id уровня>.txt`), так что её не надо строить заново после перезапуска игры.

## Первый запуск

Карту надо один раз построить — пройти уровень **с начала** (с 0%), с включённым модом, в обычном режиме. Клики при этом может играть MegaHack, мод только слушает и запоминает позиции.

После этого стартпос на 90%, 52% или чекпоинт в практике — мод сам подхватит нужный момент.

Если карты нет, а ты стартуешь с середины, бот начнёт с нуля и клики не совпадут (он это понимает и не спамит кликами в прошлом, но и пользы не будет).

## Настройки

| Настройка | Что делает |
|---|---|
| Bot enabled | включён ли бот (по умолчанию выкл) |
| Macro file | имя `.gdr2`; пусто — автоподбор по уровню |
| Start offset | ручной оффсет в секундах; `-1` — автоматически по позиции |

`F9` — включить/выключить бота прямо в игре (в лог Geode пишется `Stream Bot: enabled/disabled`).

## Фейковые смерти до процента

Настройка **Fake deaths before %** (по умолчанию 50) — бот специально умирает, пока не дошёл до этого процента, и никогда не умирает после.

Каждая попытка получает свой «процент смерти»:

```
target = 2 + (limit - 2) * random^2.6
```

Из-за степени 2.6 маленькие значения выпадают часто, а большие — редко. На лимите 50% это выглядит так: несколько смертей на 5–12%, потом ран на 20%, потом опять ранние, иногда почти 45%. То есть не «подряд 49, 43, 39», а как у человека, который учит уровень.

Процент считается по `getCurrentPercent()`, смерть — вызовом `destroyPlayer` (обычная смерть в игре, со всеми эффектами).

## Автовыбор макроса

Как у Click Indicators: при входе в уровень мод читает заголовки всех `.gdr2` в папке Click Indicators и берёт совпадающий по ID уровня, потом по названию, иначе самый свежий.

## Сборка

Локально: VS 2022 + CMake + `GEODE_SDK`. Или GitHub Actions: залить в репозиторий, Actions → Build Geode Mod → артефакт `streambot`.

## Ограничения

- Только классические уровни: в платформере X зависит от твоих нажатий, карта «время → X» не сходится.
- Нужна карта, построенная с начала уровня (см. выше).
- Нажатия идут через `PlayLayer::handleButton`, то есть в тот же кадр, что и обычный клик.
- Только Windows.
